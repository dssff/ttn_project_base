Інструкція по роботі з API

Усі дані таблиць доступні через повноцінний REST API у форматі JSON. Ви можете інтегрувати їх з будь-якою зовнішньою програмою, 1С, Telegram-ботом, мобільним додатком або веб-сервісом.

1. Інтерактивна специфікація OpenAPI / Swagger

Відкрийте /docs для тестування будь-яких запитів онлайн безпосередньо у браузері.

2. Приклади API-запитів (cURL)
curl -X GET "http://127.0.0.1:8000/api/kontragents/" -H "accept: application/json"
curl -X POST "http://127.0.0.1:8000/api/kontragents/" \
  -H "Content-Type: application/json" \
  -d '{
    "medcode": "MED-1005",
    "name": "ТОВ Нива",
    "full_name": "Товариство з обмеженою відповідальністю Нива",
    "ipn": "123456789012",
    "endpou": "12345678",
    "ur_fiz": "Юридична особа",
    "ur_address": "м. Полтава, вул. Шевченка, 10",
    "phone": "+380532112233",
    "fax": "+380532112234"
  }'
curl -X GET "http://127.0.0.1:8000/api/export/all"
